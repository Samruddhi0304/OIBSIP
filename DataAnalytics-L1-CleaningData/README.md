# Data Cleaning – Retail Sales Dataset

## Project Overview
This project focuses on cleaning and preparing a retail sales dataset using Python and Pandas.

## Objectives
- Inspect dataset structure and data types.
- Identify missing values and duplicate rows.
- Convert the Date column to datetime format.
- Check numeric columns for invalid values.
- Detect potential outliers using the IQR method.
- Save the cleaned dataset as a CSV file.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook / VS Code

## Dataset Columns
- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

## Project Files
- `data_cleaning_analysis.ipynb` – Data cleaning notebook
- `cleaned_retail_sales_dataset.csv` – Cleaned dataset
- `screenshots/` – Project output screenshots

## Conclusion
The project demonstrates basic data cleaning techniques, data quality checks, duplicate detection, date conversion, and outlier analysis.

**Note:** Actual cleaning results depend on the dataset. Potential outliers are identified for review rather than automatically removed.
