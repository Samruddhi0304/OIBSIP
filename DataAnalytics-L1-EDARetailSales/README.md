# Retail Sales Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a retail sales dataset as part of the Oasis Infobyte Data Analytics Internship.

The objective is to understand sales performance, customer demographics, product category performance, and monthly sales trends through data analysis and visualization.

## Dataset Information
The dataset contains 1,000 records and 9 columns.

**Columns include:**
- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas
- Data Visualization

## Analysis Performed
- Explored the retail sales dataset.
- Examined customer age distribution.
- Analyzed monthly sales trends.
- Compared revenue across product categories.
- Analyzed transactions by product category.
- Studied relationships between numerical variables.

## Visualizations

The `images` folder contains the following charts:

1. Customer Age Distribution
2. Monthly Sales Trend
3. Revenue by Product Category
4. Transactions by Product Category

## Project Files
- `retail_sales_analysis.ipynb` – Jupyter Notebook containing the analysis.
- `retail_sales_dataset.csv` – Dataset used for analysis.
- `images/` – Visualization charts.
- `README.md` – Project documentation.

## Conclusion
This project helped explore retail sales data, identify sales trends, understand customer demographics, and compare product category performance using Python-based data analysis.
