# House Price Prediction Using Linear Regression

## Project Overview
This project predicts house prices using Machine Learning and Linear Regression.

## Dataset
- Dataset: House Prices - Advanced Regression Techniques
- Total Records: 1460
- Total Columns: 81
- Target Variable: SalePrice

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow
1. Load and explore the dataset.
2. Perform Exploratory Data Analysis (EDA).
3. Identify and handle missing values.
4. Apply One-Hot Encoding to categorical features.
5. Perform correlation analysis.
6. Split data into 80% training and 20% testing.
7. Train a Linear Regression model.
8. Evaluate model performance using MSE, RMSE and R².
9. Visualize actual vs predicted prices and residuals.
10. Analyze important features using model coefficients.
